Shadow Lantern is a top-down stealth game: slip past patrolling guards, stay out of their vision cones, hide in the dark patches, steal the Moonstone and reach the green exit unseen. Guards patrol routes you can learn, grow suspicious when they half-see you, and chase when the alarm goes up — break line of sight and they search, then calm down. Throw a noise coin to lure a guard away, or run and risk being heard. Two galleries: The Quiet Gallery, then the Vault Wing, where sweeping security cameras join the patrols. Win unseen for a Ghost rating.

## Run it

```sh
node serve.ts # then open http://localhost:8080
```
